ИНСТРУКЦИЯ ПО САЙТУ РЕДКИСС
============================

Главное, что нужно знать:

  1_ПОСМОТРЕТЬ_САЙТ.bat   -> собрать сайт и открыть его у себя в браузере (в интернет не уходит)
  2_ОПУБЛИКОВАТЬ.bat      -> собрать сайт и выложить его в интернет

Вся рабочая папка лежит в Google Диске (программа «Google Диск» на компьютере, режим
зеркального копирования). В ней всего несколько вещей:

  ТОВАРЫ\         -> фото и видео
  товары.xlsx     -> описания, цены, соцсети
  1_...bat, 2_...bat, ИНСТРУКЦИЯ.txt
  _движок\        -> программа (внутри свои Python и Git — ничего устанавливать не нужно).
                    Руками не трогать.

Готовый сайт (папка docs) и «склад» для GitHub хранятся НЕ в Google Диске, а в скрытой папке
  C:\Users\ТВОЁ-ИМЯ\.redkiss-publish
Она создаётся и обновляется программой сама. Руками её тоже не трогать.

С двух компьютеров работать можно, но ПО ОЧЕРЕДИ, не одновременно (см. раздел 11).

Если что-то пошло не так — ничего страшного: программа никогда не стирает твои фото
и почти всегда просто пишет предупреждение, что исправить. Читай сообщения в чёрном окне.


-----------------------------------------------------------------------
1. КАК ДОБАВИТЬ ТОВАР
-----------------------------------------------------------------------

1) Открой папку «ТОВАРЫ». Там папки-категории (Обвесы, Бюсты, Фигурки).
2) Зайди в нужную категорию и создай новую папку. Название папки = название товара.
   Пример:   ТОВАРЫ\Бюсты\Лесная дева
3) Положи в эту папку фото (и видео, если есть).
4) Запусти 1_ПОСМОТРЕТЬ_САЙТ.bat — товар появится на сайте.
5) В файле товары.xlsx появится новая строка с названием твоей папки.
   Заполни описание, размер, материал, цену, статус (необязательно) и сохрани файл.
   ВАЖНО: перед запуском .bat закрой товары.xlsx.
6) Запусти 1_ПОСМОТРЕТЬ_САЙТ.bat ещё раз — проверь. Всё нравится — запусти 2_ОПУБЛИКОВАТЬ.bat.

Если не заполнять Excel — товар всё равно появится на сайте, просто без описания.


-----------------------------------------------------------------------
2. КАК ДОБАВИТЬ КАТЕГОРИЮ
-----------------------------------------------------------------------

Создай новую папку прямо в «ТОВАРЫ» (например, «Украшения») и положи в неё папки товаров.
Категория появится в меню сайта сама. Пустая категория (без товаров) в меню не показывается.

Порядок категорий в меню:
  - можно начать название папки с цифры:  1 Бюсты,  2 Фигурки,  3 Обвесы
    (цифра на сайте не показывается);
  - если цифр нет — категории идут по алфавиту.

Переименовать категорию = переименовать папку.


-----------------------------------------------------------------------
3. ФОТО
-----------------------------------------------------------------------

  - Подходят: jpg, jpeg, png, webp, heic (фото с айфона).
  - Главная фотография (обложка карточки) — первая по имени файла: 01.jpg, 02.jpg, 03.jpg...
  - Хочешь другую главную — не переименовывай всё, просто добавь в имя слово «главная»,
    например:  главная.jpg  или  Дриада главная.jpg.
  - Порядок остальных фото — по имени файла (поэтому удобно нумеровать: 01, 02, 03).
  - Имена с русскими буквами и пробелами — можно, это не проблема.
  - Тяжёлые фото не страшны: программа сама уменьшит их для сайта. Оригиналы остаются
    только у тебя на компьютере, в интернет они не попадают.
  - Если заменить фото другим с тем же именем — просто запусти .bat, программа заметит.
  - Файлы gif, bmp, tiff не поддерживаются — сохрани их как jpg.


-----------------------------------------------------------------------
4. ВИДЕО
-----------------------------------------------------------------------

  - Подходят: mp4, mov, webm. Кладётся в папку товара вместе с фото.
  - Лучше mp4. Видео запускается кнопкой, звук не включается сам.
  - Вес видео: до 40 МБ — хорошо. От 40 до 95 МБ — программа предупредит «слишком тяжёлое»,
    сайт будет медленнее. Больше 95 МБ — на сайт НЕ попадёт (GitHub не принимает файлы
    больше 100 МБ). Сожми видео бесплатной программой HandBrake и положи заново.
  - На обложке карточки у видео есть значок ▶.


-----------------------------------------------------------------------
5. EXCEL (товары.xlsx)
-----------------------------------------------------------------------

Лист «Товары» — по строке на каждый товар. Колонки:

  Папка     — название папки товара (программа заполняет сама; не меняй, иначе товар
              «потеряется» — тогда строка покраснеет).
  Название  — как называется на сайте. Пусто = берётся название папки.
  Описание  — любой текст. Переносы строк сохраняются; пустая строка = новый абзац.
  Размер, Материал, Цена — необязательно. Пусто = строка на сайте не показывается.
              Цена цифрами (4500) — на сайте будет «4 500 ₽».
              Можно текстом: «от 6000 руб», тогда покажется как написано.
  Статус    — выбери из списка: В наличии / Под заказ / Продано / пусто.
  Новинка   — напиши «да» — на карточке появится значок «Новинка».
  Скрыть    — напиши «да» — товар исчезнет с сайта (фото и строка остаются).
  Порядок   — число. Чем меньше, тем выше товар в списке. Пусто — пойдёт по общему порядку
              (см. ниже).
  Категория — только для справки, программа пишет сама. Не меняй.

Строки, у которых нет папки (например, папку переименовали), подсвечиваются КРАСНЫМ.
Новые папки программа дописывает снизу сама — вручную строки добавлять не нужно.

Общий порядок товаров на сайте:
  1. сначала товары с числом в колонке «Порядок»;
  2. потом товары, у которых папка начинается с цифры (1 Дриада, 2 Лесная дева...);
  3. потом остальные — самые новые сверху.

Excel-файл можно открывать, только пока .bat не запущен. Если запустить .bat, пока Excel
открыт, программа напишет «Закрой товары.xlsx и запусти ещё раз».


-----------------------------------------------------------------------
6. КАК СКРЫТЬ, ОТМЕТИТЬ «ПРОДАНО» ИЛИ УДАЛИТЬ ТОВАР
-----------------------------------------------------------------------

  Скрыть на время     — в Excel в колонке «Скрыть» напиши «да».
  Продано             — в колонке «Статус» выбери «Продано» (на карточке будет значок,
                        фото чуть потускнеет, товар остаётся в каталоге).
  Убрать насовсем     — удали папку товара из «ТОВАРЫ» (а в Excel строку можно оставить или
                        удалить — разницы нет, она просто покраснеет).
  Черновик            — начни название папки с _ (подчёркивание): _новая кукла.
                        Папки и файлы, начинающиеся с _ или точки, сайт игнорирует.


-----------------------------------------------------------------------
7. СОЦСЕТИ И КНОПКА «НАПИСАТЬ»
-----------------------------------------------------------------------

Лист «Настройки» в товары.xlsx:

  - Слева (колонки A-B): ссылка для кнопки «Написать мне», описание сайта (его видят
    поисковики и показывают в превью ссылки), адрес сайта (заполнится сам).
  - Справа (колонки D-E): соцсети — название и ссылка. Иконка выбирается по названию:
    Telegram, VK, Instagram, Pinterest, TikTok, YouTube, WhatsApp, Avito, Ozon, WB.
    Чтобы добавить — впиши новую строку под списком. Чтобы убрать — сотри ссылку.
    Порядок иконок на сайте — как строки сверху вниз.
  - Если ссылка на «Написать» ведёт в Telegram (t.me/...), то на странице товара в чат
    подставится готовый текст «Здравствуйте! Интересует «Название товара»».

После правок запусти .bat — изменения применятся.


-----------------------------------------------------------------------
8. ПУБЛИКАЦИЯ И ВХОД В GITHUB
-----------------------------------------------------------------------

Сайт живёт бесплатно на GitHub Pages:  https://redkisss.github.io/redkiss/
Репозиторий уже создан и Pages включены, повторять это не нужно.
(Адрес репозитория записан в файле _движок\repo.txt.)

Как опубликовать: закрой товары.xlsx -> запусти 2_ОПУБЛИКОВАТЬ.bat -> дождись слова «Готово!».
Через 1–2 минуты сайт обновится.

Вход в GitHub. При самой первой публикации на КАЖДОМ компьютере откроется окно браузера
«Sign in to GitHub» — войди в аккаунт и нажми «Authorize». Пароль в чёрное окно вводить не нужно.
Подожди 10–60 секунд, в окне появится «Готово!». Дальше компьютер запомнит вход.

Что делает 2_ОПУБЛИКОВАТЬ.bat внутри (знать необязательно): сверяется с GitHub, собирает сайт
из твоих папок в скрытую папку .redkiss-publish, сохраняет и отправляет на GitHub. Заодно кладёт
на GitHub резервную копию программы (папка backup-engine, без фото).

Перед сборкой программа проверяет, нет ли «копий» файлов вида «товары (1).xlsx» или «01 (1).jpg»
(их создаёт Google Диск, если с двух компьютеров одновременно правили один файл). Если такие
нашлись — программа остановится и покажет, какие. Оставь нужную версию, лишнюю удали.


-----------------------------------------------------------------------
9. СВОЙ ДОМЕН (когда захочется адрес вида redkiss.ru)
-----------------------------------------------------------------------

1) Купи домен у любого регистратора (reg.ru, nic.ru и т.п.).
2) В настройках домена (DNS) создай записи:
     для redkiss.ru:      четыре записи типа A:
                          185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
     для www.redkiss.ru:  запись CNAME со значением ТВОЙ-ЛОГИН.github.io
   (актуальные адреса: docs.github.com -> GitHub Pages -> Custom domain)
3) В товары.xlsx, лист «Настройки», поле «Адрес сайта» напиши: https://redkiss.ru/
4) Запусти 2_ОПУБЛИКОВАТЬ.bat (программа создаст нужный файл CNAME).
5) На GitHub: Settings -> Pages -> Custom domain -> впиши redkiss.ru -> Save,
   потом поставь галочку «Enforce HTTPS» (появится через некоторое время).
Старая ссылка github.io после этого сама перенаправит на новый домен.
Все пути на сайте относительные, поэтому ничего переделывать не надо.


-----------------------------------------------------------------------
10. ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
-----------------------------------------------------------------------

«Закрой товары.xlsx и запусти ещё раз»
   Файл открыт в Excel. Закрой Excel (или только этот файл) и запусти .bat снова.

«Не найден встроенный Python» / «Не найдены нужные библиотеки»
   Google Диск ещё не докачал папку _движок. Подожди, пока он закончит синхронизацию
   (значок в трее), и запусти .bat ещё раз. Устанавливать ничего не нужно.

«Нет кэша сжатых картинок… первая сборка может занять несколько минут»
   Всё нормально: так бывает при первом запуске на новом компьютере. Просто подожди.

«СТОП. Нашлись копии файлов с (1)»
   См. раздел 8: оставь нужную версию файла, лишнюю удали, запусти ещё раз.

Товара нет на сайте
   Проверь: в папке есть фото? Нет «да» в колонке «Скрыть»? Папка не начинается с _ ?
   Программа в конце пишет, какие папки пропущены и почему.

Товар есть, а описания нет
   В Excel в колонке «Папка» название должно совпадать с названием папки (регистр и
   лишние пробелы не важны). Красная строка = совпадения нет.

Фото не отображается
   Формат не из списка (jpg, png, webp, heic) или файл повреждён. Программа напишет
   «Не получилось открыть картинку».

Сайт на GitHub не обновился
   Подожди 2–3 минуты и нажми в браузере Ctrl+F5. Проверь, что .bat закончил словом «Готово!».

«Не прошёл вход в GitHub»
   Запусти 2_ОПУБЛИКОВАТЬ.bat ещё раз и войди в аккаунт в открывшемся окне браузера.

«Не нашёл ни одного товара... Сайт НЕ тронут»
   Папка «ТОВАРЫ» пуста, переименована или перенесена. Верни её на место и запусти ещё раз.
   Эта защита нужна, чтобы случайно не стереть сайт.

Что-то совсем непонятное
   Программа сохраняет подробности в файл ОШИБКА.txt (в рабочей папке, рядом с товары.xlsx) — пришли его мне
   (вместе со скриншотом чёрного окна), я разберусь.

Что делать НЕ нужно
   - Менять что-либо в папке _движок и в скрытой папке .redkiss-publish.
   - Работать с двух компьютеров одновременно (см. раздел 11).
   - Удалять файл товары.xlsx (если удалишь — создастся новый, но описания пропадут).
   - Делать копию сайта на GitHub-сайте через браузер (правки кнопкой Edit): они конфликтуют
     с публикацией из программы.

Советы на всякий случай:
   - Папка «ТОВАРЫ» и файл товары.xlsx в интернет не попадают. Они лежат в Google Диске
     (это уже копия в облаке), но раз в пару месяцев можно скопировать их ещё и на флешку.


-----------------------------------------------------------------------
11. ВТОРОЙ ПК (коротко)
-----------------------------------------------------------------------

  1) Установи «Google Диск» для компьютера, войди в тот же аккаунт, включи зеркальное
     копирование папки с сайтом и дождись, пока она скачается целиком.
  2) Дальше как обычно: 1_ПОСМОТРЕТЬ_САЙТ.bat / 2_ОПУБЛИКОВАТЬ.bat. Python и Git ставить не надо.
  3) Первая сборка на новом ПК дольше обычной, а при первой публикации откроется окно
     входа в GitHub — это нормально.

Главное правило: работаем с одного ПК за раз. Закончил — подожди, пока Google Диск допишет
все изменения (значок в трее «синхронизировано»), и только потом садись за другой.


-----------------------------------------------------------------------
12. КАК ВЕРНУТЬСЯ К ВЕРСИИ ДО ПЕРЕНОСА В GOOGLE ДИСК
-----------------------------------------------------------------------

Перед переделкой на GitHub сохранена «точка возврата» — метка (тег) pered-google-disk.
Это состояние программы и сайта на 07.11.2026, коммит 6cb5ce9.
Посмотреть: https://github.com/Redkisss/redkiss/tree/pered-google-disk

Вернуть СТАРУЮ ПРОГРАММУ (папки «Движок», «docs», старые .bat, как было до переноса):
  1) Скачай архив: https://github.com/Redkisss/redkiss/archive/refs/tags/pered-google-disk.zip
     и распакуй в любую папку на компьютере (не в Google Диск).
  2) Скопируй туда свои «ТОВАРЫ» (переименуй в «Товары») и товары.xlsx из Google Диска.
  3) На компьютере должны стоять Python (python.org, с галочкой «Add python.exe to PATH»)
     и Git (git-scm.com). Дальше — старые 1_... / 2_... / 3_...bat, как раньше.
  Тот же результат командами (папка redkiss-old появится там, где открыта консоль):
      git clone https://github.com/Redkisss/redkiss.git redkiss-old
      cd redkiss-old
      git checkout pered-google-disk

Вернуть САЙТ В ИНТЕРНЕТЕ к тому виду (если после переноса что-то сломалось). Это заменяет
сайт на GitHub версией с метки, поэтому делай только если уверен(а) — или напиши мне:
      git clone https://github.com/Redkisss/redkiss.git redkiss-old
      cd redkiss-old
      git checkout main
      git reset --hard pered-google-disk
      git push --force origin main
  Перед этим закрой окна 2_ОПУБЛИКОВАТЬ.bat. Дальше публикуй из старой программы.
  Новая схема при следующей публикации сама перезапишет репозиторий, если ты к ней вернёшься.
